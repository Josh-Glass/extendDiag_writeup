=== COMPUTATIONAL MODELING PLAN ===

OVERVIEW:
Need flexible, reusable workflow for DIVA and GCM modeling on Experiments 2 and 3.
Two phases: (1) A priori simulations showing model behavior across parameter space,
(2) Post-hoc fitting to quantify match to human data.

MODELS TO INCLUDE:
- DIVA (diva.py) - coherence-based, learns feature correlations
- GCM (gcm.py) - similarity-based, exemplar model
- NOT ALCOVE - we're focused on generalization, not learning dynamics

KEY REQUIREMENTS:
1. Flexible - same code structure works for both experiments
2. Fast - parameter optimization needs to be efficient
3. Well-organized - clear separation of concerns, reusable components
4. Reproducible - seeded, deterministic where possible

WORKFLOW STRUCTURE:

Phase 1: A PRIORI SIMULATIONS
Goal: Show what each model predicts across parameter space (like Exp 1 did)
- Sample parameter space systematically (grid or random sampling)
- For each parameter set, train model and get test predictions
- Focus on CRITICAL items (X vs Y in Exp 3; T3/T4 in Exp 2)
- Output: distributions of predictions showing model's behavioral repertoire
- Visualization: density plots or heatmaps showing parameter space coverage

Phase 2: POST-HOC FITTING
Goal: Find best-fitting parameters and quantify model performance
- Optimization target: minimize MSE between model and human response probabilities
- Search method: grid search for DIVA (stochastic), scipy.optimize for GCM (deterministic)
- - maybe we should use a smarter hparam optimizing method like and evolutionary algo or something???
- Fit to: aggregate human data (proportion choosing each category)
- Output: best parameters, MSE, predicted vs observed plots
- Report: which model fits better, qualitative match to patterns

- DIVA: Random sampling (e.g., 500-1000 parameter sets) due to stochasticity

- GCM: Full grid (deterministic, so exhaustive is feasible)
  - ~200-400 parameter combinations total

POST-HOC FITTING STRATEGY:
- DIVA: Coarse grid search (fewer points than a priori)

  - Select best by MSE

- GCM: scipy.optimize.minimize (Nelder-Mead or Powell)
  - Multiple random starts to avoid local minima
  - Fast because deterministic
  - - or maybe some kind of evolutionary algo or a bayesian search or something?
